# نسخه آزمایشی Tkinter

این پوشه پوسته اولیه نسخه Tkinter سامانه است و به فایل‌های PySide6 موجود دست نمی‌زند.

## اجرا

از پوشه اصلی پروژه و در محیط ۳۲ بیتی:

```powershell
python -m pip install pyodbc python-dotenv jdatetime openpyxl arabic-reshaper python-bidi
python -m tk_version.app
```

Tkinter همراه نصب استاندارد Python ویندوز ارائه می‌شود. درایور Microsoft Access ODBC باید با معماری Python/برنامه (۳۲ یا ۶۴ بیت) روی رایانه نصب باشد.

## وضعیت

فعلاً فقط پوسته مدرن، ابزار اولیه راست‌چین و ورود با همان جدول `tbluser` پیاده‌سازی شده‌اند. صفحات عملیاتی هنوز منتقل نشده‌اند. فایل‌های نسخه PySide6 در ریشه پروژه دست‌نخورده باقی مانده‌اند.

برای متن‌های نمایشی از `arabic-reshaper` و `python-bidi` استفاده می‌شود. رفتار راست‌به‌چپ، به‌ویژه در فیلدهای قابل ویرایش، باید روی Windows و فونت‌های مقصد آزمایش شود؛ Tkinter برخلاف Qt پشتیبانی RTL کاملاً بومی و یکپارچه ندارد.
